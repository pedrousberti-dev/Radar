# Cripto Radar — colocar no ar em 5 minutos

1. Cria uma conta no github.com (gratis).
2. Novo repositorio, nome `radar`, publico.
3. "Upload files" -> arrasta TODOS os arquivos desta pasta (index.html, manifest.json, sw.js, os icones).
4. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main -> Save.
5. Em ~1 min o link aparece: https://SEU-USUARIO.github.io/radar/

No celular:
- Android/Chrome: abre o link -> menu -> "Instalar app". Vira app com icone, tela cheia, notificacoes.
- iPhone/Safari: compartilhar -> "Adicionar a Tela de Inicio".

APK sem loja: https://www.pwabuilder.com -> cola o link -> Package for stores -> Android -> baixa o APK e instala.

Pra atualizar o app: troca o index.html no GitHub. Todo mundo que instalou recebe na proxima abertura.
